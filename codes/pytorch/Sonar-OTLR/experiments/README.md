# 后续复刻路线与实验约定

本文件是准备计划，不代表已经完成实现、训练或复现。

1. 数据与协议：取得完整 OpenSID；检查每类数量、文件格式与尺寸、重复图像；核对官方表与图像级折清单。没有官方折清单时，清楚区分自行划分结果和严格复现。
2. 环境：先盘点可用 Python、PyTorch、CUDA 和 GPU。论文报告 Python 3.8、PyTorch 1.13、Ubuntu 20.04、RTX 3090Ti；这是参考环境，不代表本机已配置，也不要求直接降级现有环境。
3. 最小数据管线：实现读图、标签映射与显式划分加载。示例可做流程验证，但不用于论文结果比较。
4. 基线：统一 ImageNet 预训练 ResNet-18，先跑闭集及阈值 Softmax，再核对 PLUD 官方实现、损失和阈值协议。若无官方源码，标明自行实现及差异。
5. 模块：分别实现 SAPFS（CAM、Gini、动态比例、软掩码混合）和 PTMCL（尾类队列、原型 EMA、动态过滤、监督对比），与基线组合做消融。
6. 指标与正式实验：核对 OSFM、F1、NMA、OSCR_macro 的精确定义，补充 Gmean、Macro-F1。按论文配置开放程度和类别划分，完成五组划分 × 五折后再讨论复现差距。不能把随机一次运行当作论文整体结果。

## 未来实现组织（按需创建模块）

`src/sonar_otlr/` 下按 datasets、models、losses、metrics、engine 分工；不预先堆放空实现文件。外部官方算法源码将放在独立的 `external/<仓库名>/`，记录提交号，本地实验改动放在 src。

每次运行使用 `outputs/<实验名>/<run_id>/` 保存实际配置、代码版本、种子、数据来源及划分、环境、日志、逐类指标与预测。权重放在 `checkpoints/<实验名>/<run_id>/`。当前尚无训练入口或结果文件。

论文说明缺少场景、任务、实例标识，图像级划分不能保证相应组间隔离；报告结果时保留这一限制。
