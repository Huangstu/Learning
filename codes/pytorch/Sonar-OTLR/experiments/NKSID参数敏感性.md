# NKSID 参数敏感性实验

2026-11-25。对照原论文 §6.9.1–6.9.3 与 §6.10（表 8、图 9、10、12）。本实验使用实际训练和测试结果。原始数据来自 https://github.com/Jorwnpay/NK-Sonar-Image-Dataset。

同一固定图像划分，训练 542 张，已知验证 124 张，测试 259 张（已知 124、未知 135）。五个已知训练类样本数为 160、150、125、95、12。每组 10 轮，两个训练种子 42 和 123，数据划分和批次顺序固定。每个种子训练 21 个主实验配置和 4 个 SAPFS 对照，共 50 次训练。使用原有 py311、GTX 1650 与 ImageNet 预训练 ResNet-18。保留旧的五轮实验输出。

主实验在完整模型上逐项改动参数，同时保留交叉熵基线。参考配置为 (r_min,r_max)=(0.2,0.8)、m=0.9、λ=3、ρ=0.2。固定掩码与熵对照仅启用 SAPFS 和开放集损失，以免尾类记忆影响对比。熵实现用 1−归一化 Shannon 熵映射保留比例，固定组固定的是空间位置比例，属于本地机制对照。

| 对照 | 论文结果 | 本次两种子平均 OSCR_macro |
|---|---|---|

交叉熵基线两个种子的宏平均 OSCR 为 87.98% / 83.11%，默认 SATML 为 82.91% / 90.54%。平均值分别为 85.54% / 86.72%，差 1.18 个百分点，单次差异方向相反。表中峰值是这批测试的观察结果，不作为独立选参结论。

五个已知类使尾类集合随 ρ 离散变化。0.1 与 0.2 都只有 fishing_net，0.3 与 0.4 都增加 big_propeller，0.5 再增加 cylinder。因此组内不同数值没有改变训练使用的尾类集合，观察到的分数差不宜归因于 ρ 本身。GPU 未强制确定性，两个种子也共享同一测试集，不能作为独立折或显著性检验。论文报告多个数据集及更完整协议，本实验未复现 §6.9.4 的特征可视化。

## 重跑与核验

在项目根目录使用 py311，依次运行：

```powershell
python scripts/train_satml.py --config configs/nksid_sweep.json
python scripts/train_satml.py --config configs/nksid_sweep_seed123.json
python scripts/train_satml.py --config configs/nksid_sapfs_controls.json
python scripts/train_satml.py --config configs/nksid_sapfs_controls_seed123.json
python scripts/summarize_nksid_sweep.py
python scripts/train_satml.py --evaluate checkpoints/nksid_sweep/reference.pt
```

汇总脚本验证所有配置完成 10 轮、四组运行的划分逐字节相同及两个种子的尾类映射一致。重新加载参考模型得到相同宏平均 OSCR（82.91%）。输出目录包含配置、样本划分、损失、逐图 logits、指标及双种子汇总 CSV。主实验只保存种子 42 的基线和默认 SATML 模型权重。
