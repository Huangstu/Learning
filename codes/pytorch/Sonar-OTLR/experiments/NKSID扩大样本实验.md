# NKSID 扩大训练集实验

沿用 NKSID 快速参数实验的 5 个已知类、3 个未知类和固定划分。542 张小训练集是 2,048 张扩容训练集的真子集。验证集和测试集的文件、标签及顺序逐项一致，分别为 124 张已知验证图像、259 张测试图像（124 张已知、135 张未知）。

| 训练类别 | 原训练数 | 扩容后 |
|---|---:|---:|
| floats | 160 | 891 |
| tire | 150 | 774 |
| cylinder | 125 | 228 |
| big_propeller | 95 | 143 |
| fishing_net | 12 | 12 |

扩容组共 6 个配置、2 个训练种子（42、123）。每组固定训练 8 轮、每轮 85 次更新，共 680 次。在第 220 次更新时额外评估，对齐小样本的 10 轮 × 22 次。第 220 步仅约 2.6 个扩容 epoch，等步数比较控制了更新预算，各样本被看到的次数仍有差别。8 轮为预设预算，两个检查点均用验证集校准阈值，未根据测试分数提前停止或调整参数。预训练权重、优化器、学习率、批大小和分辨率沿用先前设置。

| 配置 | 小样本 220 步 | 扩容 220 步 | 扩容 680 步 |
|---|---:|---:|---:|
| 交叉熵基线 | 85.54% | 69.87% | 87.40% |
| 默认 SATML | 86.72% | 63.09% | 77.22% |
| SAPFS 保留范围 (0.1, 0.8) | 90.31% | 62.21% | 76.62% |
| PTMCL 动量 0.99 | 87.22% | 63.22% | 77.35% |
| PTMCL 权重 1 | 90.53% | 67.52% | 78.16% |
| 尾类分位数 ρ=0.5 | 76.66% | 61.38% | 74.25% |

表内为两个种子的宏平均 OSCR。小样本与扩容配置均为局部对照，单项参数变化均基于默认 SATML，不能把各行的参数组合视为已联合测试。

- 等步数下六组在扩容后均有下降。扩容组训练至 680 步后，宏平均 OSCR 均高于各自 220 步的数值。基线相对小样本增加 1.85 个百分点，默认 SATML 下降 9.50 个百分点（差值按原始精度计算）。
- 扩容终点的默认 SATML 在 seed 42、123 分别为 70.67%、83.77%，均低于同种子基线的 89.87%、84.92%。默认 SATML 与基线的已知 Top-1 均值为 95.97% 与 99.19%，未知拒绝召回均值为 37.41% 与 57.78%。结果未支持单靠扩大训练样本就能恢复论文增益。
- 扩容后保留范围 (0.1,0.8) 的小样本优势消失。权重 1 在本次 SATML 配置中均值最高，但两个种子对它与默认权重的排序相反。ρ=0.5 的均值仍低于默认值。这是选点复查，覆盖 §6.9.3 和 §6.10 的部分参数，尚未重跑完整网格。
- 增加的是现有较多样本类别，尾类样本仍是 12 张，最大与最小类之比从约 13.3 升至 74.3。尾类集合在相同配置下与小样本一致，但批次中的尾类出现频率会变化。结果同时受样本量和类别比例影响，且两个训练种子共享同一测试集。

复跑（项目根目录，py311）：

```powershell
python scripts/train_satml.py --config configs/nksid_large_42.json
python scripts/train_satml.py --config configs/nksid_large_123.json
python scripts/summarize_nksid_scale.py
python scripts/train_satml.py --evaluate checkpoints/nksid_large_123/reference.pt
```

汇总脚本验证训练子集关系、验证与测试身份相同、全部配置和训练步数一致，并导出 outputs/nksid_scale_report/comparison.csv。种子 123 默认 SATML 的最终权重复测与记录一致。逐图 logits 在两组原始输出目录，基线与默认模型权重在对应 checkpoints 子目录。
